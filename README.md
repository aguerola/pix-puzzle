# Pix-Puzzle

Stamp/XOR grid puzzle game, ported to Flutter (iOS, Android, web) with [flutter_bloc](https://pub.dev/packages/flutter_bloc).

## App

```bash
cd pix_puzzle
flutter pub get
flutter run
```

Launch configs for **debug**, **profile**, and **release** are in [`.vscode/launch.json`](.vscode/launch.json).

## Layout

| Path | Contents |
|------|----------|
| `pix_puzzle/` | Flutter source |
| `pix_puzzle_v2.apk` | Original Android APK (Git LFS) |
